# Security Policy

## Reporting a vulnerability

If you find a security issue in Smart Tab Organizer, please report it privately rather than opening a public issue.

- Email: vivek@bytebox.network
- Or use the machine-readable contact at [https://smarttab.bytebox.network/.well-known/security.txt](https://smarttab.bytebox.network/.well-known/security.txt) (RFC 9116)

Please include steps to reproduce, the affected version (`manifest.json` version or Chrome Web Store version), and your browser/OS. We'll acknowledge reports as soon as possible and credit reporters in `RELEASE_NOTES.md` unless you'd prefer otherwise.

## Scope

This is a client-side Chrome extension with no developer-controlled backend. In scope: the extension code (`background.js`, `popup.js`, `options.js`, `rules.js`), the manifest/permissions, and the documentation site at `smarttab.bytebox.network`. See `PRIVACY_POLICY.md` for what data the extension accesses.
